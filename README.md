# Terraform Docker NGINX Project

## Overview

This project demonstrates Infrastructure as Code (IaC) using Terraform to manage an NGINX web server running in a Docker container.

Terraform manages the NGINX Docker image and container, while Docker provides the environment in which the web server runs.

## Objectives

- Learn Terraform fundamentals.
- Define infrastructure using configuration files.
- Manage Docker resources with Terraform.
- Deploy and verify a running NGINX web server.
- Practice infrastructure lifecycle management.

## Technologies Used

- Terraform
- Docker
- NGINX
- Ubuntu 24.04 on WSL2
- Git and GitHub

## Project Structure

```text
terraform-docker-project/
├── main.tf
├── .gitignore
├── .terraform.lock.hcl
└── README.md
```

The `.terraform.lock.hcl` file is included when generated by Terraform. The `.terraform/` directory and local state files are excluded from version control.

## Prerequisites

- Docker Desktop installed and running.
- Terraform installed.
- Ubuntu or another compatible Linux environment.
- Git installed.

## Configuration

The `main.tf` file defines the Docker provider, the `nginx:alpine` image, and a Docker container named `terraform-nginx-web`.

The container exposes port 80 internally and port 8081 on the host.

## Deployment

Initialize Terraform:

```bash
terraform init
```

Review the planned changes:

```bash
terraform plan
```

Create the resources:

```bash
terraform apply
```

Type `yes` when Terraform requests confirmation.

## Verification

Check the web server response:

```bash
curl -I http://localhost:8081
```

A successful deployment should return an HTTP response such as `200 OK`.

List Terraform-managed resources:

```bash
terraform state list
```

Expected resources:

```text
docker_container.web
docker_image.nginx
```

You can also open `http://localhost:8081` in a browser.

## Cleanup

When finished experimenting, remove the resources managed by this Terraform configuration:

```bash
terraform destroy
```

Review the proposed changes and confirm when prompted. This removes the Terraform-managed container and image; it does not uninstall Docker or Terraform.
